# SnowFree — playable demo

A short browser demo of SnowFree: you control a loose, riderless snowboard instead of a skier.

## Play

Open the published page, or download `index.html` and open it in any modern browser. It is a single self-contained file: markup, styles, game code, and the pixel font are all embedded, so it needs no internet connection, server, or extra files.

## Controls

- **Left / Right** or **A / D** — carve and traverse the slope
- **Up** or **W — tuck for extra acceleration
- **Down** or **S** — brake and slide sideways
- **Space / left-click / tap** — small hop
- **P** — pause

Run over skiers to build a Vengeance Score chain, dodge rocks, trees and rough snow, and survive the ski patrol and the yeti. Wanted levels bring patrol squads, and at five stars a helicopter drops fresh pursuit every few seconds — hit it with a rainbow ramp to bring it down.
